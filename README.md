# shooting-game-test

スマートフォン向け（縦画面想定）のシンプルなブラウザシューティングゲームです。
HTML / CSS / JavaScript だけで動作し、追加のビルド環境や外部依存は不要です。

## 起動方法

1. このリポジトリをローカルに配置します。
2. `index.html` をブラウザで開きます。
   - 例: VS Code の Live Server や、任意の静的ファイルサーバー
   - 直接ファイルを開いても基本動作します

## 操作方法

- **スマホ操作**
  - 画面下の「左」「右」ボタンをタップ、または押し続けるとプレイヤーが左右移動します。
- **PC操作**
  - `←` / `→` キー、または `A` / `D` キーで左右移動できます。
- 弾は自動発射されるため、移動操作だけで遊べます。

## ゲーム概要

- 上から敵（障害物）が落下してきます。
- 弾が敵に当たると敵を倒し、スコアが加算されます。
- 以下の条件でゲームオーバーになります。
  - 敵がプレイヤーに接触したとき
  - 敵が画面下端に到達したとき
- ゲームオーバー時は表示される「リスタート」ボタンで再開できます。

## 画面仕様

- スマートフォン縦画面を主対象にしたレスポンシブUIです。
- 画面サイズや向きが変わってもゲーム領域が崩れにくい構成です。
- タッチ操作時のスクロールや誤操作を抑えるため `touch-action` と `preventDefault` を適用しています。
