# shooting-game-test

スマートフォンの**縦画面専用**で遊ぶ、シンプルなブラウザ向けシューティングゲームです。
外部ライブラリ・ビルド環境は使わず、`index.html` / `style.css` / `script.js` だけで動作します。

## 起動方法

1. このリポジトリをローカルに配置する
2. `index.html` をブラウザで開く
   - もしくは静的サーバーを使う場合: `python3 -m http.server 8000`
3. ブラウザで `http://localhost:8000` にアクセスする

## 重要仕様

- **縦画面専用**です。横向きの場合はゲームを停止し、「縦画面にしてください」と表示します。
- ゲームはブラウザの現在セッションのみで完結します。
  - バックエンドなし
  - セーブ/ロードなし
  - localStorageなし
  - ページ再読み込みで状態は初期化されます

## 操作

### スマホ

- 画面下部の「左」「右」ボタンを押している間だけ移動
- タッチ操作でスクロールや選択が起きないよう `touch-action` と Pointer Events を利用

### PC

- `←` / `→`
- `A` / `D`

## ゲーム内容

- プレイヤーは自動射撃します
- プレイヤーは画面端で停止し、画面外には出ません
- HP制を採用
  - 被弾でHP減少
  - HPが0でゲームオーバー
  - 被弾直後の連続減少防止のため短いダメージ無敵時間あり
- ゲームオーバー画面にスコアを表示し、リスタート可能

## 敵の種類

敵は複数種類あり、見た目・HP・速度・得点・ダメージ・ドロップ率が異なります。

- 通常型（normal）
- 耐久型（tough）
- 高速型（fast）

## アイテムドロップ

- 敵撃破時、敵種類ごとの確率でアイテムをドロップ
- アイテムは落下し、プレイヤーが触れると即時取得・即時発動

## アイテム効果

- **シールド**: 次の被ダメージを1回だけ無効化（複数取得で加算）
- **一定時間無敵**: 一定時間ダメージ無効（再取得で残り時間へ加算）
- **攻撃力アップ**: 一定時間、弾ダメージ上昇（再取得で時間延長）
- **攻撃スピードアップ**: 一定時間、自動射撃の間隔を短縮（下限あり）
- **移動スピードアップ**: 一定時間、左右移動速度を上昇
- **HP回復**: HPを回復（最大HPを超えない）

## 被弾処理の優先順

1. 一定時間無敵中なら無効化
2. シールドがあれば1個消費して無効化
3. それ以外でHP減少

## HUD表示

プレイ中に以下を表示します。

- スコア
- HP / 最大HP
- シールド数
- 時間制効果（無敵・攻撃UP・連射UP・移動UP）の残り時間
